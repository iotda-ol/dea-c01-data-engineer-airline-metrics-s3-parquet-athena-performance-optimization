# dea-c01-data-engineer-airline-metrics-s3-parquet-athena-performance-optimization
This repository implements a DEA-C01 compliant data lake. It automates raw CSV-to-Parquet conversion using AWS Glue and S3 Partitioning to optimize Amazon Athena query performance. By ensuring Regional Colocation, it reduces latency and minimizes costs via columnar storage and predicate pushdown.
